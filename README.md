# 🥋 Plataforma de Campeonatos de Jiu-Jitsu

Este projeto visa desenvolver uma plataforma digital para a organização e gestão de campeonatos de Jiu-Jitsu, facilitando a inscrição de atletas, o agendamento de lutas e a divulgação de resultados.

## 📌 Funcionalidades Principais

* Cadastro de atletas e academias
* Criação e gerenciamento de eventos e campeonatos
* Sistema de chaves e categorias por faixa etária e graduação
* Atualização em tempo real dos resultados das lutas
* Painel administrativo para organizadores([Esportes SP][1])

## 🚀 Tecnologias Utilizadas

* Frontend: React.js
* Backend: Node.js com Express
* Banco de Dados: MongoDB
* Autenticação: JWT (JSON Web Tokens)
